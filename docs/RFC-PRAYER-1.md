# RFC-PRAYER-1: Optional Malaysia prayer companion

Add a dependency-free Java TV module, `:tv:prayer`, at the existing TV application layer, and bundle its signed release APK and public digest/signer pin with the phone app. An explicit Home-screen Add action invokes the existing journalled `PlanRequest.AddModule`; Remove uses `RemoveModule`. No planner interface, remote index signature, launcher pin, Home safety rule or phone permission is relaxed. AppGraph inspects the packaged companion and verifies both public pins before handing it to the flow. The Play flavour does not expose this sideload. Installation itself starts no audio or alarms; selecting a Malaysian zone, adding the feature and enabling audio are explicit on-TV choices. The two bundled CC BY 3.0 recordings distinguish Fajr from the four regular prayers. A dated, validated JAKIM zone schedule supplies exact alarm events, with opt-in playback and a bounded full-screen overlay that does not claim kiosk control. Physical firmware compatibility remains to be verified. TV runtime permissions and data/audio attribution are documented in `tv/prayer/README.md` and `ATTRIBUTION.md`.
