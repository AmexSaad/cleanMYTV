# Optional cleanMYTV Home

The existing upstream launcher has its own signing identity; the project cannot ship an in-place update using that private key. Prayer Time version 3 therefore adds an optional native `HomeActivity` within its existing, consistently signed package. It provides an inline dock add button, a live prayer widget, and direct PackageManager discovery of both TV and ordinary Android apps. The existing Home remains installed and enabled. Android's Home settings asks the user to select Prayer Time; the installer never changes the default Home or device-owner policy silently.

The additive `RemoteDir.PRAYER_HOME` permits only the companion's existing external-files directory. `ConfigTransport.forLauncher` defaults to the existing transport and FileOverlayTransport restricts its alternate component to the fixed Prayer Time Home class. The planner routes config and wallpaper to that directory only when installing this version of the companion, or when the probed default Home is that exact component. Existing plans and directories remain unchanged. A snapshot reads the selected Home's overlay, and module removal refuses to remove the currently resolved Home. These are reviewed changes to the fork's typed vocabulary; no arbitrary directory, command, launcher, new signing identity or automatic Home takeover is introduced.
